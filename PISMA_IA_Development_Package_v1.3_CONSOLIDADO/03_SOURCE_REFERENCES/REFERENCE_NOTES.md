# Notas das Fontes Corporativas de Referência

Estes arquivos ajudam a IA a compreender a origem do produto. **O PRD v1.3 prevalece** quando houver diferença.

## Permissão de Trabalho

- `FS 13-01 - Permissão de Trabalho (PT ) Rev.00 PT.docx`: formulário corporativo original recebido.
- `PT_FS13-01_Rev05_PROPOSTA_MELHORADA.docx`: proposta revisada que serviu de base funcional para o módulo PT.
- `Relatorio_Melhorias_PT_FS13-01_Rev05.md`: fundamentação e comparação da revisão.

## Audicamp

- `FS 02-04 Audcampo - Rev 02 13-07-21.xlsx`: modelo corporativo que inspirou categorias e fluxo do módulo Audicamp.
- `audcampo_frente.png` / `audcampo_verso.png`: renderizações visuais do formulário, quando disponíveis, para compreensão de layout/campos.

## Retirada de resíduos

- `MODELO - PEDIDO RETIRADA DE RESÍDUO.doc`: modelo de Solicitação de Retirada de Resíduos. Ele deve orientar o módulo de retirada e não ser confundido com o PREA.

O documento de retirada contém, entre outros elementos, solicitante, prestador, dados da operação, tipo/quantidade do resíduo, local de descarte, veículo/funcionários, autorizações, registro de saída e comprovação/ticket de descarte. No software, campos específicos devem ser ativados conforme aplicabilidade e parametrização da Obra/contrato.

## Privacidade de exemplos

Os documentos podem conter nomes, números de documentos, CNPJ, telefones, placas ou dados operacionais de exemplo. Esses valores **não devem ser usados como seed real, credencial, dado padrão ou conteúdo público**. Use dados sintéticos na implementação e testes.
